## U-20261102-01 · 2026-11-02 · 要求 Python 3.11，不再支援 3.10 · #migration #deps #ci

- **原因**：工作區的所有套件一起把最低版本提高到 Python 3.11。Pillow 13.0.0 等安全修正版本只支援 3.11 以上，繼續支援 3.10 會讓 lock 保留有已知弱點的舊版本。
- **變更**：`requires-python` 改為 `>=3.11`，移除 3.10 classifier；CI 矩陣從 3.11 開始；文件中寫著 3.10 的最低版本改為 3.11。
- **Lock**：
  - `.github/requirements/runtime.txt`: regenerated for 3.11; dropped 3.10-only entries: `tomli`.
  - `.github/requirements/test.txt`: regenerated for 3.11; dropped 3.10-only entries: `exceptiongroup`, `tomli`, `typing-extensions`.
- **其他**：`test.txt` 與 `runtime.txt` 依 `architecture.md` 記錄的指令重新產生，只移除 3.10 專用條目；ruff 目標改為 py311。
- **Lint**：ruff 改以 py311 為目標後會啟用新規則：`timezone.utc` 改成 `datetime.UTC`（UP017）；UP042（`StrEnum`）先忽略，因為改用 `StrEnum` 會改變 `str()` 的輸出。
- **待辦**：無。
